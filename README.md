# SMALL-ATM-IN-C++-
Attached is a small ATM that has an attached file with it. In the file, the data is arranged in this order:
1. name
2. surname
3. account number
4. account balance
5. password
   
The program itself offers the possibility of checking the account number or account balance. Also, the user can pay himself or someone else money in 2 different ways. If someone new wants to log in, it is also possible at the ATM.

![image](https://github.com/user-attachments/assets/ba713aca-98c8-4b3b-b46b-63c1e0bc99ab)

The goal of this project was to show that an interesting program that simulates a system from the real world can be made with C++. In order to function at the ATM, we can do the same with this program. It is important that the program is adaptable, that it offers the opportunity to choose the option that needs to be done and that the opportunity to choose appears every time again until we decide to leave the program. It is important when adding or removing money from the account that it is actually added/removed due to the correctness of the data it stores.

I did this project after finishing my first year at the Electrical Engineering Department, so my knowledge of saving data was limited to saving it to a text file. If we wanted to improve the program, we would definitely be able to connect the C++ code to a database from which we will use data and into which we will enter data.
